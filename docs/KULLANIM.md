# Halberion Nexus — hızlı kullanım

**Geliştiren:** Azat Berkan Ölçer

**Yayınlayan:** Halberion Studio

1. Windows x64 paket ZIP'ini bir klasöre çıkarın.
2. `HalberionNexus.exe` dosyasını çalıştırın; ek .NET kurulumu gerekmez.
3. Sağ üstteki dil menüsünden **Sistem dili**, **Türkçe** veya **English** seçin.
4. Home ekranındaki canlı donanım/ağ özetini kullanın; modüllere soldaki menüden geçin.
5. Bir sistem değişikliği gerekiyorsa kapsamı okuyun ve yalnızca istediğiniz işlemi açıkça onaylayın.

Network Monitor'de izlenecek bağdaştırıcıyı seçin; Wi‑Fi, PdaNet ve VMware adaptörleri ayrı satırlar olarak görünür. Trafik grafiği adaptör toplamıdır. Uygulama bağlantı tablosu IPv4 bağlantı uçlarını PID ile eşler; uygulama başına indirilen/yüklenen bayt toplamını sağlamaz.

System Control gerçek sensör değerlerini gösterir. Sıcaklık/fan sensörleri donanım tarafından sunulmuyorsa tahmin edilmez. Oyun FPS ölçümü için resmi PresentMon konsol aracını indirip uygulamadaki dosya seçimiyle tanıtın; CPU/GPU meşguliyet değerleri PresentMon sürümüne bağlıdır.

Device Control'de Bluetooth aksesuar listesinden fare, klavye ve kulaklık gibi cihazların Windows tarafından bildirilen durumunu inceleyin. Eşleştirme/bağlanma işlemlerini Windows Bluetooth ayarlarından yapın. Disk analizinde yinelenen dosya taraması SHA-256 ile eşleşme doğrular ve hiçbir şeyi silmez. Güvenli temizlik seçtiğiniz tek dosyayı onaydan sonra Geri Dönüşüm Kutusu'na yollar.

Windows hotspot ve PdaNet sınırları, sensör desteği ve diğer ürün sınırları `README.md` içinde açıklanır. Nexus, donanım performans artışı veya FPS/RAM kazanımı garantilemez ve PdaNet bağlantısını kendiliğinden sıfırlamaz.
